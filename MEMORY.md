# Durable project boundaries

- Product: Google Antigravity Desktop reliability/governance harness. This repository
  alone is source; existing .gemini and named desktop plugin are explicit runtime
  targets. Neighbor engine files are not global Antigravity rules.
- Source/runtime/private state remain distinct. .gemini-private is a sync marker,
  not an OS boundary. Hashes are integrity/correlation metadata, not signatures.
- Keep historical failures and rejected Claims. Never substitute newest-file
  selection, a new task identity or a new root for a referenced evidence chain.
- Attempts and Tool Operations are different. Missing Post means unresolved;
  unknown/opaque results are unclassified, never guessed successful.
- External checker authority is unavailable. Valid local evidence may reach
  checking; missing/stale evidence remains unverified.
  Independent code review improves testing but does not create OS actor identity.
- force_ask did not gate writes in the tested desktop version. Sentinel and v3.5.1
  binding deny had historical live proof; v4's five scoped lifecycle stages and
  terminal/ADS refusals are now observed, not all host capabilities.
- Historical case-02 Canary is read-only. Its output SHA256 is
  89ac5efd0fa00f40e54c12c103927ec4894c917c0c227edc37d46cbef28f1346.
- Requested exit 7 and host tool code 1 were distinct observations; child exit and
  the responsible transformation layer were not independently established.
- Strict unavailable until actual isolation is proven. Guarded is same-user
  bypassable; terminal Cwd and keyword blacklists do not define write scope.
- Knowledge: source fidelity differs from external truth; original-read capability
  is required. Canonical final-claim propagation is mechanical, semantic truth is not.
- No real Obsidian edits/install without separate authorization. No commit/push/PR
  in the v4 convergence task. Historical root snapshots: docs/changelog-v3.md.
- Production closeout: both acceptance Attempts stopped, Binding revoked revision 3.
  First Attempt evidence points to an output changed by a later test: preserve the
  stale historical reference, do not rewrite it to get Gate success. Future terminal
  evidence must use fixed snapshots. Scoped readiness is not canonical completion.
